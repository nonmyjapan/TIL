github プル・プッシュの方法
 =====

プル方法<br> 
① 更新したいファイルの一つ上の階層で Shift+Enter → Git Bash を開く  
② git pull origin main  
- pull は正常に完了し、ローカルが最新の状態

更新後プッシュ方法<br> 
① 更新したいファイルの一つ上の階層で Shift+Enter → Git GUI を開く  
② 編集した個所をステージング
③ コミットメッセージを書く・commitボタンを押す  
④ pushボタンを押す  
完了
