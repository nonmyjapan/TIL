学習目標(仮)
-
◎SQL・Linuxコマンド（最優先：実務直結）
現職で「ガンガン使う」のであれば、ここを最優先にするのがメンタル面でも技術面でも最も効果的です。
メリット: 勉強したことが翌日の仕事ですぐに役立ち、実務での失敗やストレスが激減します。現場の先輩からも「呑み込みが早い」と評価されやすくなります。
学習のコツ: 完璧な暗記を目指すのではなく、現場でよく使う基本コマンド（cd, ls, grep, tail -f 等）や基本的なSQL（SELECT, JOIN, GROUP BY）を日常業務でスラスラ打てるレベルを目指しましょう。

◎Oracle Certified Java Programmer, Bronze（次点：Javaの基礎固め）
研修の記憶が新しいうちに資格を取るという戦略は大正解です！
メリット: Bronzeの出題範囲は「Javaの基本文法」や「オブジェクト指向の基礎概念」が中心です。資格勉強を通じて、3ヶ月の研修で曖昧だった部分の穴埋めができます。
目標時期: 「今年度中」と言わず、「あと1〜2ヶ月以内」など期限を絞って一気に取得してしまうのがおすすめです。ダラダラやると研修の記憶が薄れてしまい、逆に効率が悪くなります。黒本（『オラクル認定資格教科書 Javaプログラマ Bronze SE』）を1冊周回するのが近道です。
