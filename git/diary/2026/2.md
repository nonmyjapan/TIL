条件分岐
=
if文
```
public class IfExample {
    public static void main(String[] args) {
        int score = 85;

        // 条件に応じて処理を分岐
        if (score >= 90) {
            System.out.println("評価: A");
        } else if (score >= 70) {
            System.out.println("評価: B"); // scoreが85なのでここが実行される
        } else {
            System.out.println("評価: C");
        }
    }
}
```
for文（繰り返し）
```
public class ForExample {
    public static void main(String[] args) {
        // iが0から始まって、5未満の間（0, 1, 2, 3, 4）繰り返す
        for (int i = 0; i < 5; i++) {
            System.out.println(i + "回目の処理です");
        }
    }
}
```
拡張for文
=
```
public class EnhancedForExample {
    public static void main(String[] args) {
        String[] fruits = {"りんご", "みかん", "バナナ"};

        // 配列の要素を1つずつ取り出して処理
        for (String fruit : fruits) {
            System.out.println("フルーツ: " + fruit);
        }
    }
}
```
